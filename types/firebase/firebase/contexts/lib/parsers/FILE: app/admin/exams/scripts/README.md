# NVD.JLPT - Nền tảng Học và Luyện thi Tiếng Nhật Thực Chiến

NVD.JLPT là một hệ thống giáo dục trực tuyến toàn diện, hỗ trợ học viên từ N5 đến N1 với các module Flashcard, Kanji, Ngữ pháp và hệ thống Luyện đề trắc nghiệm tính giờ chuẩn xác.

## 🚀 1. Yêu cầu hệ thống
- **Node.js**: Phiên bản >= 18.x
- **Git**: Cài đặt Git để clone và quản lý mã nguồn.
- Tài khoản **Google/Firebase** (Miễn phí).
- Tài khoản **Vercel** (Miễn phí) để deploy.

## 🛠 2. Hướng dẫn cài đặt Local (Môi trường phát triển)

### Bước 1: Clone dự án và cài thư viện
```bash
git clone [https://github.com/your-username/nvd-jlpt.git](https://github.com/your-username/nvd-jlpt.git)
cd nvd-jlpt
